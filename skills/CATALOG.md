# Skill catalog

Canonical skills live here; host wrappers are generated. Start with the
orchestrator, then read specialist procedures only when relevant.

Use **sdlc-orch** as the preferred entry name in both hosts. It routes to the
existing orchestrator procedure; the longer name remains supported.

- [sdlc-orch](sdlc-orch/SKILL.md): Preferred short entry point for the existing orchestrator.
- [sdlc-orchestrator](sdlc-orchestrator/SKILL.md): Route software delivery requests through the Agentic SDLC framework, selecting a proportional workflow and relevant specialist skills.
- [sdlc-specification](sdlc-specification/SKILL.md): Create measurable software specifications and Software Design Descriptions for features or new projects with material design scope.
- [sdlc-architecture](sdlc-architecture/SKILL.md): Assess software boundaries and SOLID tradeoffs, and record consequential architecture choices in ADRs.
- [sdlc-planning](sdlc-planning/SKILL.md): Build phased software delivery plans, RACI ownership and traceability for multi-step implementation work.
- [sdlc-implementation](sdlc-implementation/SKILL.md): Implement authorized software changes in coherent slices, preserving active contracts and adding relevant regression checks.
- [sdlc-verification](sdlc-verification/SKILL.md): Verify software acceptance criteria and evidence, review changes, and report scoped completion with remaining gates.
- [sdlc-review-cycle](sdlc-review-cycle/SKILL.md): Run a bounded multi-lane review cycle with parallel reviewers, capped builder fix rounds, an approver and a recorded human decision.
- [sdlc-handoff](sdlc-handoff/SKILL.md): Prepare or consume an evidence-backed software delivery handoff when resuming work or moving between assistant sessions.
