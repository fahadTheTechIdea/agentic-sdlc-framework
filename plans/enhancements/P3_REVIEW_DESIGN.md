# Phase 3: review and delivery — design

Goal: satisfy REQ-007 with a reviewable branch/PR and honest evidence.

Review the full diff for preservation, policy contradictions, SOLID tradeoffs,
traceability, credentials and unsupported completion claims. Run required local
checks and record exact results and patch identity. Keep live host pilots and
owner decisions open. Commit and publish the feature branch; create a draft PR
targeting the observed default branch. Do not merge or tag a release.

If remote write access fails, retain the local commit and provide an applicable
patch plus assessment instead. Report the actual access failure without claiming
that a PR exists. Completion of this phase means a reviewable proposal, not
owner acceptance or production certification.
