# Phase 3: review and delivery — design

Goal: satisfy REQ-007 with reviewable commits, the owner's authorized Git workflow
and honest evidence. The initial baseline PR is merged; current maintenance is
directly on master only, as explicitly requested by the owner.

Review the full diff for preservation, policy contradictions, SOLID tradeoffs,
traceability, credentials and unsupported completion claims. Run required local
checks and record exact results and patch identity. Keep live host pilots and
owner decisions open. Commit and publish authorized changes directly on master.
Do not create additional branches or PRs unless explicitly requested. Release
tagging and deployment remain separate authorized actions.

If remote write access fails, retain the local commit and provide an applicable
patch plus assessment instead. Report the actual access failure without claiming
that publication succeeded. Completion of this phase means reviewable publication, not
owner acceptance or production certification.
