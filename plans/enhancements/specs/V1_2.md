# Specification: framework v1.2 baseline

Status: implemented and published on master; live acceptance gates remain open.
Date: 2026-10-19.
Authorization: original request to assess/propose or implement the baseline,
followed by explicit owner instructions to merge and use master only. Maintain
this repository directly on master; do not create further branches or PRs unless requested.
Accountable decision role: repository owner; policy/release acceptance pending.

Original problem: the intended framework repository contained no operational framework.
Provide a portable baseline without inventing unavailable conversation detail.

| ID | Acceptance criterion | Check |
| --- | --- | --- |
| REQ-001 | Canonical constitution, engineering and evidence rules are navigable | Manifest and local link validation; review |
| REQ-002 | One orchestrator selects focused skills and proportional workflows | Skill catalog/wrapper checks; scenario review |
| REQ-003 | Codex, Claude and generic sessions have usable entry instructions | Adapter sync checks; live host pilots pending |
| REQ-004 | SDD/RACI/ADR/plans/verification/handoff templates exist | Required-file checks; JSON contract tests |
| REQ-005 | Validation rejects missing files, broken links, invalid evidence/RACI and drift | Negative regression tests |
| REQ-006 | Adoption preserves existing project instructions and refuses collisions | Installer integration tests |
| REQ-007 | Changes preserve existing history and follow the owner's current master-only workflow | Git diff, commits, merged baseline ancestry and master publication |
| REQ-008 | Application workflows require shared Log/Audit/Notification Services, UI notifications for UI apps and no swallowed exceptions | Canonical standard, skill routing, design/verification matrices and application-specific failure checks |

Non-goals: agent runtime, model/provider selection, production deployment,
compliance certification, universal application tests, global installation,
exact reconstruction of unavailable historical assistant text.
